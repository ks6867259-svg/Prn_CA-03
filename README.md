# 💰 Expense Tracker

A modern full-stack Expense Tracker web application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). The application helps users manage their personal finances by tracking income, expenses, budgets, and financial reports through a clean and responsive interface.

---

## 🚀 Features

- 🔐 User Authentication (Login & Register)
- 📊 Interactive Dashboard
- 💰 Add Income
- 💸 Add Expenses
- 📜 Transaction History
- 📈 Reports & Analytics
- 🎯 Budget Management
- 👤 User Profile
- ⚙️ Settings
- 📱 Fully Responsive Design
- 🔒 Secure JWT Authentication
- ☁️ MongoDB Database

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/25070521294.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm start
```
